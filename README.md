# Mirage

**An LLM-powered adaptive SSH honeypot.**

Mirage pretends to be a vulnerable Linux server. When an attacker logs in, they get a
shell that feels real: files, processes, services, and plausible answers to commands
nobody scripted in advance, generated by an LLM. Behind the scenes Mirage records the
whole session, profiles the attacker, maps what they did to MITRE ATT&CK, and streams
it to a live dashboard.

**Mirage never executes attacker commands.** Every reply is simulated, and anything an
attacker tries to download is only hashed and stored as an inert blob.

## Highlights

- Realistic SSH server with weak-credential bait and full session recording
- Deterministic fake system (virtual filesystem, ~40 native commands) for speed and consistency
- AI shell for everything else, with prompt-injection defence and cost budgets
- Pluggable LLM layer: Groq for live replies, Gemini for analysis, Ollama as local fallback
- Automatic MITRE ATT&CK mapping, attacker intent and bot-vs-human classification
- Live dashboard: attack map, analytics, ATT&CK heatmap, session replay

## Quick start (development)

```bash
uv sync
cp .env.example .env
docker compose up -d      # postgres + redis
uv run pytest
```

## Disclaimer

Mirage is a defensive research tool. Run it only on infrastructure you own or are
authorised to use, and isolate it from anything you care about.
